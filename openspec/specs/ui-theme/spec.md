# ui-theme Specification

## Purpose
Superseded by `ui-design-system` capability (unified dark-neumorphic token architecture). This spec is retained for archival reference; new visual-system work uses `ui-design-system` instead.

## Archived Requirements (Superseded)

### REMOVED: Requirement: Modern Blue Aesthetics
*Reason*: Describes the legacy pink/purple/magenta glassmorphism brand — including a `#E91E8C → #9C27B0` gradient button and MUI Theme Provider dependency — none of which reflect the current dark neumorphic teal/cyan/blue system. MUI is not installed in this project.
*Migration*: See `ui-design-system` spec — "Brand Hue Token Palette" and "Surface Scope Classes" requirements.

### REMOVED: Requirement: Global Typography
*Reason*: Content relocated, not removed — folded into the unified `ui-design-system` spec so all visual-system requirements live in one capability. Behavior unchanged: Manrope remains the primary typeface.
*Migration*: See `ui-design-system` spec — "Typography Token" requirement.
